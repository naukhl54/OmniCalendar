# OmniCalendar 📅🎨 - Kalender Kartun Nuansa Netral

Aplikasi kalender dan perencana jadwal pribadi dengan tampilan **kalender meja kartun estetik** (*cozy cartoon desk planner*) yang bernuansa netral, hangat, dan ramah pengguna. 

Dilengkapi dengan sistem **Urutan Prioritas yang muncul saat menekan shortcut khusus (`P`)**.

---

## ✨ Fitur & Desain Baru

- **Desain Kartun Estetik & Nuansa Netral (*Warm Neutral Palette*)**:
  - Tampilan buku kalender meja kartun dengan detail **cincin spiral binder** di bagian atas.
  - Palet warna netral yang menyejukkan mata: krem kertas hangat (*ivory paper*), garis tepi kartun tegas (*cartoon ink border*), bayangan timbul (*drop shadow 3D*), dan tipografi bulat (*Fredoka & Quicksand*).
  - Chip acara didesain seperti pita selotip washi (*washi tape*) dan catatan tempel kartun.
- **⚡ Urutan Prioritas Khusus Shortcut (`P`)**:
  - Tampilan utama kalender tetap bersih, rapi, dan tidak sesak oleh filter permanen.
  - Saat menekan tombol **`P`** pada keyboard (atau mengeklik tombol pintas prioritas), **Papan Urutan Prioritas** akan langsung terbuka!
  - Menampilkan semua tugas yang dikelompokkan secara rapi dari:
    1. 🔴 **Prioritas Tinggi (Mendesak & Penting)**
    2. 🟡 **Prioritas Sedang**
    3. 🟢 **Prioritas Rendah (Santai)**
  - Klik acara pada papan prioritas untuk langsung melihat atau mengedit rinciannya.
- **Tampilan Kalender Lengkap**:
  - **Tampilan Bulan**: Kalender bulanan dengan nomor tanggal stempel kartun dan pintasan hari.
  - **Tampilan Minggu**: Jadwal 7 hari dengan grid jam (00:00 - 23:00) yang proporsional.
  - **Tampilan Hari**: Rincian acara satu hari penuh yang fokus.
- **Kategori Warna Netral-Pastel**:
  - *Pekerjaan & Proyek* (Slate Denim)
  - *Pribadi & Kehidupan* (Sage Green)
  - *Olahraga & Kesehatan* (Dusty Rose)
  - *Belajar & Studi* (Warm Ochre)
  - *Penting & Mendesak* (Terracotta)
  - *Keluarga & Sosial* (Muted Mauve)
- **Pengulangan Acara Rutin**:
  - Mendukung acara harian, mingguan, bulanan, dan tahunan.
- **Pengingat Nada Melodis & Pop-up**:
  - Nada pengingat melodis harmonis (C-E-G) menggunakan Web Audio API tanpa file audio eksternal.
  - Pemberitahuan *toast* kartun dan integrasi notifikasi browser desktop.
- **Cadangan & Penyimpanan**:
  - Tersimpan otomatis di `localStorage`.
  - Ekspor dan impor data format JSON, serta muat data demo kartun.

## ⌨️ Daftar Pintasan Papan Ketik (*Keyboard Shortcuts*)

| Tombol | Fungsi |
| :--- | :--- |
| **`P`** | **Membuka / Menutup Papan Urutan Prioritas (Tinggi → Sedang → Rendah)** |
| `C` | Tambah Acara Baru |
| `T` | Lompat ke Hari Ini |
| `M` | Beralih ke Tampilan Bulan |
| `W` | Beralih ke Tampilan Minggu |
| `D` | Beralih ke Tampilan Hari |
| `←` / `→` | Pindah ke Periode Sebelumnya / Berikutnya |
| `Esc` | Menutup modal atau papan prioritas |
